### Maid-TaCZ Guns Balance Adjustments Fix
A mod designed to address the game balance issues that arise when TouhouLittleMaid maids use TaCZ guns.

This mod was created to prevent situations where maids obliterate enemies at lightning speed, rendering the player useless.


### Main Features
- The maid no longer fires continuously in fully automatic mode; she now fires in bursts.
- The bullets fired by the maid no longer hit their target 100% of the time; they now spread to some extent.
- Customizable each parameter for each gun type in the Config.

### Dependencies
- This mod requires [TouhouLittleMaid](https://www.curseforge.com/minecraft/mc-mods/touhou-little-maid) and [TaCZ](https://www.curseforge.com/minecraft/mc-mods/timeless-and-classics-zero).
